# Require explicit evidence for personalization updates

Personalization Contract entries may be proposed only from explicit, dated Personal Institution records and become active only after the user confirms them. Opaque chat history is not a durable personalization source; a chat may become one only when the user deliberately captures it as an observation. This keeps personalization inspectable, correctable, and under user authority.

## Consequences

Contract candidates must reference their supporting and contrary records. A skill may use current conversation context to be helpful, but must not persist an inferred preference, trait, or identity claim without the evidence-and-confirmation path.

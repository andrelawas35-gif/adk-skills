# Use two-tier skill-aware grilling lenses

## Context

The original lenses required every flat component to be resolved or explicitly
marked not applicable. That supplied coverage but made conversations feel like
checklists and treated epistemic quality as a mandatory gate.

## Decision

Keep the Agreement Loop as the sole conversational engine. Each lens now has:

- 2–3 obligatory gates derived only from authority or consent,
  irreversibility or external consequence, and privacy or data boundaries;
- a default escalation branch that information value may override; and
- one poseable pressure scenario.

Coverage is “gates accounted for + branches visited.” Unvisited non-gate
branches need not be recorded. Epistemic-quality material remains available for
escalation but is never a gate.

## Consequences

This reduces mechanical completeness and allows silence about low-value
branches. The trade-off is accepted because the harm-bearing boundaries remain
explicit. Revisit if an unvisited epistemic branch would have caught a shipped
mistake, an unrecorded branch matters in a post-mortem, or a pressure scenario
becomes stale after its skill changes.

# Expire revisable personalization by default

Working-method and Active-lens entries become inactive when their review trigger passes unless the user explicitly renews them. Inactive entries remain as historical evidence but no longer guide skills. Hard-boundary entries remain active until explicitly revised, because privacy, consent, safety, and authority rules should not disappear through inattention.

## Consequences

Every revisable contract entry requires a review trigger. Skills must ignore inactive entries by default and may surface them only as past context, clearly marked as inactive.

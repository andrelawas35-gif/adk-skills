# Govern personalization as a revisable contract

Personalization across Personal Institution and Work Studio will be represented as a versioned Personalization Contract rather than repeated fixed prose inside skills. Each tendency is explicitly user-approved and carries scope, supporting and contrary evidence, confidence, and a review trigger. The contract may guide a relevant skill but cannot establish identity or silently turn observations into permanent rules.

## Considered options

- A revisable, evidence-backed contract — accepted.
- A static personal lens repeated in every skill — rejected because it can become stale, over-applied, and difficult to audit.
- No personalization — rejected because it discards useful continuity and forces every session to start from generic defaults.

## Consequences

Personal Institution should own the private evidence and proposed updates; Work Studio should consume only approved, relevant contract entries. Skill instructions should state the boundary and fall back to neutral behavior when no applicable entry exists.
